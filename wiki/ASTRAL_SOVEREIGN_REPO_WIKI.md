# 世界觀與環境設定 (World & Environment Lore)

## 諸天三界位面體系
《星宿劫源：太初道主》構築了一個由低向高遞進的宏偉立體位面宇宙：

### 1. 下界 · 蒼瀾九域 (Nine Azure Mortal & Spirit Domain)
- **地理風貌**：凡人國度與修仙靈脈交錯。靈氣濃郁之地被傳承萬年的古修宗閥牢牢佔據，底層散修常年為幾株三清靈草血流成河。
- **代表區域**：
  - **青玄道域**：萬里秀麗靈山，乃太虛玄劍宮分舵與散修互市之地。
  - **棲霞山散修坊市**：魚龍混雜的修真市集，常有蒙塵古寶與黑市交易。
  - **靈泉斷天涯**：天地靈脈交匯之幽谷，適合布設聚元陣開闢私人洞府。

### 2. 荒古禁域 · 殞神墟 (Ruins of Fallen Gods)
- **位面性質**：上古諸神大戰沉淪的世界殘片，每三百年方顯化一次空間入口。
- **環境特質**：空間亂流肆虐，萬劫血海瀰漫。生長著突破洞天境不可或缺的「三清通脈草」。各派真傳弟子在此相互獵殺，殘酷無比。

### 3. 中界 · 無垠太虛星河 (Boundless Astral River)
- **位面性質**：跨越登仙天門後進入的浩瀚界域。星海無垠，星島浮空。
- **核心樞紐**：
  - **天樞聖城**：懸浮於星河之巔的永恆巨城，由諸天商盟共同執掌，城中設有天下聞名的天樞拍賣行與星宿宮。
  - **碎星深空**：虛空巨獸橫行的狂暴星域，誕生有三十六種大荒玄煞神火與七十二道神霄天罰雷種。

### 4. 太始魔窟 · 冥淵裂谷 (Rift of Stygian Depths)
- **位面性質**：九幽深淵之底，大道法則扭曲之地。萬劫魔煞宗總壇所在。
- **兇險特質**：空間斷層遍布，常有上古魔祖殘魂復甦，修士需以純陽辟邪之寶護體方能踏足。

### 5. 九霄登仙古階 · 太初天門 (Celestial Stair of Primordial Genesis)
- **位面性質**：通往太初真仙聖界的終極道台。
- **天威試煉**：在此需硬抗九九無量滅世混沌神雷天罰。唯有道心不朽、肉身成聖者方可叩開天門，證道萬界道尊！

# 開發者與工程架構指南 (Developer & Architecture Guide)

## 前端客戶端技術棧 (Client Architecture)
- **架構模式**：純原生 ES6 模組化單頁應用（SPA），零第三方重型框架打包依賴。
- **渲染管線**：HTML5 語義化結構 ＋ 現代 CSS3 Flex/Grid ＋ Web Animations API。
- **音訊工程**：Web Audio API 自主程序化合成器 (`client/js/engine/audio.js`)，支援自震盪音階合成，免加載外部 MP3/WAV。
- **適配範圍**：手機 9:16 直屏、摺疊螢幕與平板寬螢幕自適應。

## 服務端技術棧 (Backend Architecture)
- **核心架構**：Node.js 18+ ＋ Express RESTful API ＋ WebSocket 實時通信。
- **防作弊設計**：
  - 戰鬥採用確定性隨機種子回放驗證 (`/api/v1/combat/verify`)，拒絕客戶端本地單方判定勝負。
  - 離線掛機結算強制以服務端伺服器時間為準。
- **Google Play 結帳校驗**：
  - 接入 Google Play Developer API（Server-to-Server 驗證），雙重校驗 `purchaseToken` 與 `productId`，徹底阻斷外掛假充值。

## Android 發行封裝規範 (Google Play Android Project)
- **開發環境**：Android Studio Iguana / Jellyfish，Gradle 8.0+。
- **配置指標**：
  - `minSdkVersion`: 24 (Android 7.0+)
  - `targetSdkVersion`: 35 (Android 15)
  - `compileSdkVersion`: 35
  - ABI 支援架構：`arm64-v8a`, `armeabi-v7a`, `x86_64`
- **打包指令**：
  ```bash
  cd android
  ./gradlew bundleRelease
  ```
  產出上架專用 `.aab` 檔案（位於 `android/app/build/outputs/bundle/release/`）。
