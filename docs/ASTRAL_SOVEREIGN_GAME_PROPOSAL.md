# 第一章 專案立項全案概覽與商業戰略

## 1.1 企劃立項宗旨
《星宿劫源：太初道主》是一款專為全球移動端（Google Play 首發）打造的原創東方高概念玄幻修真放置圖文 RPG。
本專案旨在解決當前修仙手遊市場「重度 3D MMO 發熱卡頓、同質化嚴重」以及「傳統文字 MUD 界面簡陋、數值付費逼氪」的雙重痛點，開創兼具「極高文學沉浸感（小說體動態戰況播報）」＋「硬核修仙小說法則（凡根逆命、歲月藥園、天地煞火、殺人奪寶摸屍、九重雷劫飛升）」＋「輕度休閒閉關放置」的全新市場品類。

## 1.2 核心產品定位與獨特賣點 (USP)
- **純原創宏大玄幻命名體系**：徹底摒棄傳統套路化名詞，建立涵蓋九階道境、太初五極本源、大荒玄煞神火與神霄天罰的全新宇宙名詞庫。
- **掌天歲漏與時光催熟閉環**：將「時間加速」作為遊戲核心機緣，玩家每日凝練歲月靈精催熟萬年古藥，親手煉製九品神丹，打破大教宗閥對修行資源的血統壟斷。
- **雙生熔爐：煞火與神雷融爆**：自由收服大荒玄煞神火（幽冥碧髓炎、大日梵天炎）與神霄劫雷（天罡辟邪雷、都天紫極雷），於體內熔爐融合引爆滅世合璧大神通。
- **黑市暗鬥與城外設伏奪寶 (Kill & Loot)**：完全還原修仙小說殘酷法則。在拍賣行拍得道圖出城必遭截殺，玩家可反向設下【九曜星河劍界】伏擊反殺，百分之百繳獲敵修隨身納戒。
- **純原生輕量化與零外部資源加載**：客戶端基於現代 ES6 模組架構，內建 Web Audio API 國風程序化音效引擎，無外部音檔或圖片網路依賴，冷啟動小於 0.5 秒。

# 第二章 宏觀世界觀、諸天三界位面志與萬年編年史

## 2.1 諸天三界宏觀位面架構
本遊戲構築了一個由低向高遞進的立體多元宇宙：
```
[鴻蒙太虛真仙聖界] ── 宇宙本源 / 九大仙域 / 大道道果爭奪 / 太初道主
        ▲
        │  (九九無量滅世混沌神雷天罰)
[無垠太虛星河 · 中界] ── 天樞聖城 / 碎星深空 / 萬界商盟 / 神火神雷孕育地
        ▲
        │  (通虛破界天門)
[蒼瀾九域 · 下界] ── 青玄道域 / 殞神墟 / 冥淵裂谷 / 宗閥壟斷 / 散修血路
```

### 1. 下界 · 蒼瀾九域 (Nine Azure Mortal & Spirit Domain)
- **地理風貌**：凡人國度億萬，而靈脈天地被各大修仙古族與正魔大教世代把持。下界資源極度匱乏，普通修士終其一生難獲一枚三清通脈丹。
- **核心區域**：
  - **青玄道域**：蒼瀾古陸中心，秀麗靈山綿延萬里，太虛玄劍宮分舵所在地。
  - **棲霞山散修坊市**：魚龍混雜的黑市交易區，無宗門庇佑之散修在此擺攤互市。
  - **靈泉斷天涯**：天地靈脈微弱分支交匯處，主角開闢私人閉關洞天之地。

### 2. 荒古禁域 · 殞神墟 (Ruins of Fallen Gods)
- **環境特質**：太古仙魔大戰崩碎的殘破位面，每隔三百年方開啟一次空間裂隙。
- **法則壓制**：內部瀰漫萬劫血煞與空間亂流，生長著突破洞天境的通脈靈草，各派真傳在此展開慘烈屠戮。

### 3. 中界 · 無垠太虛星河 (The Boundless Astral River)
- **位面格局**：穿過登仙天階後進入的宏偉星域，星島懸浮，大能橫渡虛空。
- **核心樞紐**：
  - **天樞聖城**：星河中央不朽神城，由諸天商盟執掌，禁制私鬥，拍賣行匯聚諸天至寶。
  - **碎星深空**：狂暴星域，盤踞著以星核為食的虛空巨獸，孕育天地玄煞火種與雷源。

### 4. 太始魔窟 · 冥淵裂谷 (Rift of Stygian Depths)
- **極惡絕地**：位於九幽深淵底部，空間斷層犬牙交錯，萬劫魔煞宗總壇與萬古魔祖沉睡之地。

### 5. 九霄登仙古階 · 太初天門 (Celestial Stair of Primordial Genesis)
- **天道終點**：通往太初真仙界的登仙台，在此降下九九無量滅世混沌天劫，渡劫成道則萬界共尊！

## 15.1 前端客戶端技術規格
- **技術棧**：HTML5 語義化結構 ＋ 現代 CSS3 (Flex/Grid) ＋ 原生 ES6 模組架構 (`type="module"`）。

- **適配與響應式**：9:16 手機直屏標準（`max-width: 480px` 視窗居中，支援寬螢幕折疊設備與平板自適應）。

## 15.2 後端微服務技術規格
- **技術棧**：Node.js 18+ ＋ Express 4.18 ＋ WebSocket 實時雙向通信。
- **核心接口全景**：
  - `POST /api/v1/auth/login`：訪客設備標識快速認證，簽發 JWT 令牌。
  - `POST /api/v1/user/sync-save`：太虛玉簡存檔雲端同步備份。
  - `GET /api/v1/arena/leaderboard`：萬界天梯排行榜實時查詢。
  - `POST /api/v1/combat/verify`：戰鬥隨機種子回放驗證，杜絕修改攻擊力外掛。
  - `POST /api/v1/billing/verify-google-play`：Google Play Developer API 雙向收據校驗。

## 15.3 Google Play 上架與合規專項規格
1. **Android Gradle 構建配置**：

   - `compileSdkVersion`: 35
   - ABI 支援架構：強制支援 `arm64-v8a`, `armeabi-v7a`, `x86_64`。
