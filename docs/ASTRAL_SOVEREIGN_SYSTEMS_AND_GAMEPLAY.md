# 第三章 確定性戰鬥演算引擎與鬥法播報規格書 (Combat Engine & Mechanics Spec)

## 3.1 核心架構與確定性特性
戰鬥引擎 (`client/js/engine/combat.js`) 為純邏輯、無渲染依賴的有限狀態機。輸入為 `(PlayerEntity, EnemyEntity, RandomSeed)`，輸出為包含每回合每一步動態日誌與血量快照的 `CombatResultObject`。完全保證相同種子在客戶端與服務端執行結果 100% 絕對一致。

## 3.2 回合生命週期事件流 (Turn Lifecycle)
```
OnRoundStart ──> ProcessBuffs ──> CheckDeath ──> SpeedSort ──> 
Action[0] (先攻) ──> CheckDeath ──> Action[1] (後攻) ──> CheckDeath ──> 
TickCooldowns ──> OnRoundEnd
```

### 單一行動行為步驟 (Action Sub-steps)
1. **控制狀態檢定**：檢定對象是否帶有 `stun` 或 `paralyze`。若存在，跳過出招並生成麻痹日誌。
2. **神通輪換檢定**：遍歷已裝配道訣（上限 4 門），依序檢定 `curCd == 0 && currentMP >= skill.qiCost`。若命中則扣除真元、重置冷卻；若無可用道訣，降級為普通護體指芒。
3. **破虛閃避判定**：
   $$	ext{IsDodge} = 	ext{Random}(0, 100) < 	ext{Defender.DodgeRate} 	imes 100$$
4. **傷害計算與護甲穿透**：
   $$	ext{ArmorPenMultiplier} = 1.0 - 	ext{Attacker.ArmorPen}$$
   $$	ext{EffectiveDef} = 	ext{Defender.Def} 	imes 	ext{ArmorPenMultiplier}$$
   $$	ext{BaseDmg} = \max\left(20, \, 	ext{Attacker.Atk} 	imes 	ext{Skill.Power} - 	ext{EffectiveDef} 	imes 0.45
ight)$$
5. **會心暴擊檢定**：
   $$	ext{IsCrit} = 	ext{Random}(0, 100) < 	ext{Attacker.CritRate} 	imes 100$$
   $$	ext{CritMul} = 	ext{IsCrit} \, ? \, \left(1.8 + 	ext{Attacker.ExtraCritDmg}
ight) : 1.0$$
6. **最終傷害施加與減傷罩**：
   $$	ext{FinalDmg} = \lfloor 	ext{BaseDmg} 	imes 	ext{CritMul} 	imes 	ext{Defender.ShieldReduction} 	imes 	ext{Random}(0.95, 1.15)

7. **附加狀態觸發**：若招式附帶灼燒/麻痹/沉默，依命中幾率向受擊方 Buff 列表追加實例。

## 3.3 小說體動態戰況演繹語法引擎
戰鬥播報日誌採用金庸/古龍/忘語風格的動態模板引擎，支持標籤替換：
- `{att}`：攻擊者角色名。
- `{def}`：受擊者角色名。
- `{skill}`：釋放之神通道訣名稱。
- `{dmg}`：結算之最終傷害數字。

## 5.4 融火煉雷演算法
